# 安装与升级

Relay 发布形态为 **Linux 单二进制（musl 静态链接）+ 前端静态资源**，无任何外部运行时依赖。支持 x86_64 与 arm64 两种架构。

| 方式 | 适用场景 | 难度 |
|---|---|---|
| [在线安装](#在线安装推荐)（推荐） | 服务器可访问 GitHub | ⭐ 一条命令 |
| [离线安装](#离线安装) | 内网 / 无法访问 GitHub | ⭐⭐ 手动下载两步 |
| [Docker Compose](#docker-compose) | 容器化环境 | ⭐⭐ |
| [源码构建](#源码构建) | 二次开发 | ⭐⭐⭐ |

---

## 在线安装（推荐）

参考 1Panel 的快速安装体验，**一条命令 + 交互引导**完成全部安装（下载 → 配置端口与管理员密码 → 注册 systemd → 健康检查）：

```bash
curl -fsSL https://raw.githubusercontent.com/stoneaigc/Relay/main/deploy/install-online.sh -o install-online.sh \
  && sudo bash install-online.sh
```

脚本会依次：

1. 检测系统架构（x86_64 / arm64）与 root 权限；
2. 查询 GitHub 最新 Release 版本；
3. **交互引导**（全部有默认值，直接回车即可）：安装目录（默认 `/opt/relay`）、服务端口（默认 `8080`）、管理后台用户名（默认 `admin`）与密码（默认自动生成 16 位强密码）；
4. 自动生成 `relay.env`（含随机 JWT 密钥，`chmod 600`），systemd 启动时自动注入；
5. 下载并安装对应架构的发布包，注册 `relay` systemd 服务；
6. 健康检查通过后打印访问地址、账号信息与常用命令。

安装完成示例：

```
============================================================
  ✔ Relay v0.2.1 安装成功!
============================================================
  管理后台 : http://192.168.1.10:8080/admin/
  用户门户 : http://192.168.1.10:8080/portal/
  管理账号 : admin
  管理密码 : xK7dP2mQ9rT4vW6y  (已写入 /opt/relay/relay.env,请妥善保管)
  修改管理密码 : 编辑 /opt/relay/relay.env 中 RELAY_ADMIN__PASSWORD 后重启服务(systemctl restart relay)
============================================================
```

### 免交互安装（CI / 自动化）

所有提问都可用环境变量跳过：

```bash
sudo NONINTERACTIVE=1 \
  RELAY_PORT=9000 \
  RELAY_ADMIN_PASSWORD='Your-S3cret-Password' \
  bash install-online.sh
```

支持的变量：`RELAY_VERSION`（指定版本）、`INSTALL_DIR`（默认 `/opt/relay`）、`RELAY_PORT`（默认 `8080`）、`RELAY_ADMIN_USERNAME`、`RELAY_ADMIN_PASSWORD`、`REPO`（仓库）、`DL_PREFIX`（下载加速镜像前缀）。

### 安装后你可以访问

| 地址 | 说明 |
|---|---|
| `http://<IP>:<端口>/admin/` | 运营管理后台 |
| `http://<IP>:<端口>/portal/` | 用户门户（注册 / Key 管理 / 用量） |
| `http://<IP>:<端口>/healthz` | 健康检查（返回版本号） |
| `http://<IP>:<端口>/v1/...` | 数据面 API（OpenAI / Anthropic 协议） |

## 离线安装

服务器无法访问 GitHub（或想先在本地审阅再上服务器）：

### 1. 获取发布包

- 从 [GitHub Releases](https://github.com/stoneaigc/Relay/releases/latest) 下载 `relay-<版本>-linux-<架构>.tar.gz`（`x86_64` / `arm64` 对应服务器架构），上传到服务器；
- 或在有网的同架构机器上用源码打包：`./deploy/build.sh`（产物在 `deploy/dist/`，结构与 CI 包一致）。

### 2. 安装

```bash
tar xzf relay-*.tar.gz && cd relay-*/
sudo ./install.sh          # 默认装 /opt/relay,可用 INSTALL_DIR=/your/path 覆盖
```

`install.sh` 的行为：

- 自动创建 `relay` 系统用户（服务不 root 运行）；
- 安装二进制与前端资源到安装目录；
- **首次**写入默认配置 `config/default.toml` 与敏感配置模板 `relay.env`；**已存在则原样保留**（升级时不会覆盖线上改动）；
- 注册 systemd 服务并启动，SQLite 数据库落在安装目录（`User=relay` 可写）。

> ⚠️ 默认管理员为 `admin / Relay@123`、JWT 密钥为开发默认值——**生产环境务必在启动前覆盖**：编辑 `/opt/relay/relay.env` 写入 `RELAY_ADMIN__PASSWORD` 与 `RELAY_AUTH__JWT_SECRET`，或直接采用上面的在线安装（自动生成）。

## 升级

### 方式一：一键在线升级（推荐）

发布包与安装目录内均带有 `upgrade.sh`：

```bash
sudo bash /opt/relay/upgrade.sh          # 升级到最新 Release
sudo bash /opt/relay/upgrade.sh 0.2.1    # 或指定版本
```

脚本流程：查询最新版本 → 与运行中服务的版本比对（相同则跳过）→ 下载对应架构包 → **备份当前二进制**（`relay.bak.<时间戳>`）→ 调用 `install.sh` 原地升级（配置与数据全保留）→ 健康检查。

### 方式二：管理后台检查更新

管理后台 →「设置 → 软件更新」→ 点击「检查更新」。发现新版本时会给出 Release 链接与升级指引（要求服务器可访问 GitHub API；仓库为私有或离线时优雅降级提示）。

### 方式三：手动升级（离线）

下载新版发布包 → 解压 → 在解压目录执行 `sudo ./install.sh`——与首次安装同一条命令，配置与数据自动保留。

### 回滚

升级失败或想退回旧版本：

```bash
cp /opt/relay/relay.bak.<时间戳> /opt/relay/relay
sudo systemctl restart relay
```

## Docker Compose

```bash
docker compose up -d --build        # 默认 SQLite,数据落 named volume
curl http://localhost:8080/healthz
```

容器镜像升级：`docker compose pull && docker compose up -d`（使用预构建镜像时）或重新 `--build`。

> compose 中的 `RELAY_AUTH__JWT_SECRET` / `RELAY_ADMIN__PASSWORD` 默认注释态，对外部署前务必覆盖。

## 源码构建

```bash
git clone https://github.com/stoneaigc/Relay.git && cd Relay
./deploy/build.sh                   # 产物:deploy/dist/relay-<版本>-linux-<架构>.tar.gz
```

本地构建为宿主动态链接，musl 静态包以 [CI Release](https://github.com/stoneaigc/Relay/releases) 为准。

## 卸载

```bash
sudo systemctl disable --now relay
sudo rm -rf /opt/relay /etc/systemd/system/relay.service
sudo userdel relay                  # 可选:删除专用用户(先确认数据已备份/迁移)
```

> 卸载前请备份 `/opt/relay` 下的 SQLite 数据库文件（默认 `relay.db`）与 `relay.env`。
