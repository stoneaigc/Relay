# 功能介绍 · 用户门户

入口：`http://<IP>:<端口>/portal/`。面向**终端用户**：注册领额度、创建 API Key、看用量、在线试模型。用户可见的模型由运营者在后台**绑定的模型组**决定——组外模型完全不可见。

---

## 注册 / 登录 / 找回

- **邮箱验证码**注册与登录；忘记密码走邮箱验证码找回。
- 未配置 SMTP 时为开发模式（验证码打日志），生产环境请在管理后台「设置」配置发件邮箱。
- 登录防爆破：连续失败触发滑动窗口限流。

## 概览

登录后的首页：当前**余额**、关键用量数字、**用量趋势图**（ECharts：请求量 / tokens / 费用走势），一眼看清自己的消费节奏。

## 模型广场

所有可用模型的展示页（按标签筛选，含各类目计数）。每张模型卡展示模型名、上下文长度、单价、标签等——先逛广场挑模型，再去对话页或接 API。

## 对话

在线聊天测试：从自己可见的模型中任选一个开聊，流式输出。适合接 API 前快速验证模型效果，也可以当作日常问答工具。

## 奖励

展示运营者配置的奖励任务（拉新、实名等），用户提交申领后进入「审核中」，管理后台通过后额度自动入账。状态一目了然：审核中 / 已通过 / 已驳回。

## 对话日志

每一笔对话调用的账单明细：

| 字段 | 说明 |
|---|---|
| 时间 | 调用发生时间 |
| 模型 | 对外模型名 |
| 输入 / 输出 | tokens 数（含计费 tokens 说明） |
| 耗时 | 该次请求耗时（ms） |
| 费用 | 本次调用扣除的额度 |
| 缓存 | 语义缓存命中状态（命中部分按折扣计费） |

## API 文档

面向调用方的接入文档，左侧目录跟随滚动：鉴权方式（Bearer Key）、协议端点（OpenAI / Anthropic）、流式调用、常见错误码、**API Key 生命周期**（掩码显示、随时复制、刷新轮换），示例代码 curl / Python / Node 一键复制。

## API Key 管理

在「概览」页的接口卡片中创建与刷新 Key——**OpenAI 接口 / Anthropic 接口各一把**，卡片同时展示 Base URL，复制即接：

- Key 形如 `rk_live_...`，界面以掩码显示，随时一键复制完整值；
- 「刷新 Key」重新生成，旧 Key 立即失效（旧版本创建的 Key 无法回显，刷新一次即可复制）；
- Key 即身份：调用量、费用、日志都归属到 Key 所属用户。
